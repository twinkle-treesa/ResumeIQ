# ResumeIQ

An AI-powered Resume Reviewer that analyzes resumes and provides detailed feedback using Google Gemini AI.

## Features

- Upload PDF resumes
- AI-powered resume analysis
- Resume score and ATS score
- Strengths and weaknesses analysis
- Missing skills suggestions
- Download analysis report as PDF

## Tech Stack

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- Google Gemini API
- PyMuPDF
- Docker
- AWS Elastic Beanstalk


## Installation

```bash
git clone <repository-url>
cd resumeiq
pip install -r requirements.txt
```
